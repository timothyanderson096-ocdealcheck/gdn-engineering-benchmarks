The first hosted event run [41188324221](https://github.com/timothyanderson096-ocdealcheck/gdn-engineering-benchmarks/actions/runs/41188324221) remains failed: its Python receive thread lost packets during the near-full control, and its shutdown assertion required a CLI ACK that POSIX shutdown does not always return before process exit. This revision uses a separately reviewed native raw recorder on the same socket, with exact source/binary identity, final status and zero-loss controls. It records the actual parameter-query transmit offset rather than assuming the intended 10 ms scheduling delay. The revised shutdown observation preserves actual CLI 0 or silent 255 and requires joint owned-process, fresh terminal marker, natural exit 0 and no-signal evidence; it does not manufacture an ACK or waive another failure. Complete 65535/65536 delivery and the revised observation must pass a fresh hosted run before any success claim. Original failed artifacts are preserved.
