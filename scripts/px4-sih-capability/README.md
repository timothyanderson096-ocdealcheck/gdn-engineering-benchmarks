# Unchanged PX4 SIH readiness recovery

The first standard hosted run, [41186705281](https://github.com/timothyanderson096-ocdealcheck/gdn-engineering-benchmarks/actions/runs/41186705281), passed all 226 native tests, including the 27 previously blocked daemon/POSIX tests, and built full SITL. Its overall capability result remains incomplete: our smoke helper incorrectly required nonempty forwarded client stdout from `mavlink status`. Actual PX4 source uses raw `printf` for that status, and the full instance dump appears in the daemon log. The preserved failed artifact is not relabelled.

This separate job keeps the original five helper files unchanged and reuses their reviewed setup/source functions plus exact dependency constraints. It builds full SITL on unchanged `789389fd46fcfb8473544d2fb3eeabd85893294c`, generates the source-pinned MAVLink decoder and starts the normal disarmed SIH airframe in a new rootfs. It does **not rerun the unchanged native test suite** or apply a candidate patch.

A bounded readiness loop requires real disarmed `vehicle_status`, successful SIH and MAVLink status exits, and two actual CRC-decoded disarmed heartbeats from system/component 1/1 on loopback UDP 14580 → 14540. The launched native PID must own the expected transmitting socket. MAVLink status client stdout is retained even when empty; the actual daemon log retains its raw status output. No status text, socket, native process or packet is mocked.

Normal shutdown is always attempted and its actual outcome retained, including after an earlier failed control. The shared strict contract requires the owned native process to be alive before the exact CLI request, natural process exit 0 within the deadline, and a fresh terminal `Exiting NOW.` marker after the recorded pre-request log offset, without signals or earlier unexpected failures. CLI 0 is recorded as `ACK_OBSERVED`. Only CLI 255 with completely empty combined output may be classified `NOT_OBSERVED_SOURCE_PERMITTED_SHUTDOWN`: the pinned POSIX source permits shutdown to terminate the daemon before its RPC return trailer. This does not prove the exact thread schedule, an RPC acknowledgement, or that every shutdown hook/resource drained. Other nonzero results, forced cleanup, missing readiness, timeouts or source changes remain failed. `shutdown-proof.json` preserves those details; old failed runs remain unchanged.

Recovery run [41188692241](https://github.com/timothyanderson096-ocdealcheck/gdn-engineering-benchmarks/actions/runs/41188692241) passed readiness but failed its former CLI-exit-0-only assertion while the owned native process naturally exited 0 with the terminal marker and no forced cleanup. This revision corrects that observation contract and must pass a fresh run. The earlier failed result remains failed. See the shared [source contract](../px4-event-range/CONTRACT.md) for the pinned shutdown implementation and the strict accepted outcomes.

Raw heartbeat bytes, timestamps, endpoint/source metadata, module attempts, native logs, dependency/source pins and real process exits are retained as ordinary Actions artifacts. The outer watchdog identifies the exact native process group from a PID/start-time journal if cleanup must be forced.

This proves normal SIH startup and loopback readiness only. It does not claim protocol-regression, candidate, board, full-CI, physical flight, human review or upstream acceptance. No PX4 source commit, personal DCO, sign-off or PR is created. Prepared with AI assistance as independent verification evidence.
